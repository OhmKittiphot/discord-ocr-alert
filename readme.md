# Discord OCR Alert

Discord OCR Alert เป็นบอท Python สำหรับสแกนข้อความบนหน้าจอจากเกมหรือแชทที่เปิดบนหน้าจอ แล้วใช้ OCR (Optical Character Recognition) ในการอ่านข้อความและแจ้งเตือนผ่าน Discord เมื่อพบคำที่กำหนดไว้

## คุณสมบัติ

- จับภาพหน้าจอแบบกำหนดพื้นที่ (region)
- อ่านข้อความจากภาพด้วย Tesseract OCR
- ตรวจจับข้อความที่ตรงกับ keyword ที่กำหนด
- ป้องกันข้อความซ้ำด้วยระบบ deduplicate
- ส่งข้อความแจ้งเตือนไปยัง Discord Webhook
- ทำงานแบบวนลูปด้วยช่วงเวลาในการสแกนที่กำหนดได้

## โครงสร้างโปรเจกต์

- `bot.py` : ไฟล์หลักที่ทำงานทั้งหมด
- `requirements.txt` : รายการ dependency ที่จำเป็น
- `readme.md` : คู่มือการใช้งาน

## ข้อกำหนดเบื้องต้น

ก่อนใช้งาน คุณต้องมีสิ่งต่อไปนี้:

- Python 3.9+ หรือเวอร์ชันที่เข้ากันได้
- Tesseract OCR ที่ติดตั้งในเครื่อง
- Windows (เพราะโค้ดกำหนด path ของ Tesseract แบบ Windows โดยตรง)
- Discord Webhook URL สำหรับช่องที่ต้องการรับแจ้งเตือน

## การติดตั้ง

1. Clone หรือ download โปรเจกต์นี้ลงเครื่อง
2. เปิด terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์
3. ติดตั้ง dependency

```bash
pip install -r requirements.txt
```

## การติดตั้ง Tesseract OCR

หากเครื่องยังไม่มี Tesseract ให้ติดตั้งจาก:

- https://github.com/UB-Mannheim/tesseract/wiki

หลังจากติดตั้ง ให้ตรวจสอบว่า Tesseract ถูกติดตั้งแล้วด้วยคำสั่ง:

```bash
tesseract --version
```

ถ้าไม่ได้อยู่ใน PATH หรือไม่ใช่ค่า default คุณสามารถตั้งค่า path ในไฟล์ `bot.py` ได้ตรงส่วนนี้:

```python
pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
```

## การตั้งค่าโปรเจกต์

เปิดไฟล์ `bot.py` และแก้ค่าตรงส่วนที่ระบุด้านบน:

```python
REGION = {"top": 500, "left": 20, "width": 500, "height": 200}

TARGET_TEXTS = [
    "Secret",
    "Eternal",
    "Divine",
]

DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/..."

CHECK_INTERVAL = 90
```

### 1) ตั้งค่าพื้นที่หน้าจอ

`REGION` คือพื้นที่บนหน้าจอที่ต้องการให้บอทสแกน เช่น บริเวณแชทเกมหรือแชทใน Roblox

คุณต้องปรับพิกัดให้ตรงกับจอของคุณ:

- `left` : ตำแหน่ง x เริ่มต้น
- `top` : ตำแหน่ง y เริ่มต้น
- `width` : ความกว้าง
- `height` : ความสูง

> ควรใช้ตำแหน่งที่ครอบคลุมเฉพาะแถบข้อความที่ต้องการสแกน เพื่อให้ OCR ถูกต้องและลดการแจ้งเตือนผิดพลาด

### 2) ตั้งค่าคำที่ต้องการจับ

`TARGET_TEXTS` เป็น list ของคำหรือวลีที่ต้องการค้นหา เช่น:

```python
TARGET_TEXTS = ["Secret", "Eternal", "Divine"]
```

บอทจะค้นหาว่าแต่ละบรรทัดมีข้อความที่ตรงกับคำเหล่านี้หรือไม่ และส่งแจ้งเตือนทันทีเมื่อเจอ

### 3) ตั้งค่า Discord Webhook

ใส่ Discord Webhook URL ของช่องที่ต้องการแจ้งเตือน

```python
DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/your_webhook_url"
```

> ควรเก็บ URL นี้ไว้เป็นความลับ เพราะคนอื่นสามารถใช้งาน webhook นี้เพื่อส่งข้อความเข้าช่องได้

### 4) ตั้งค่าความถี่ในการสแกน

```python
CHECK_INTERVAL = 90
```

หมายความว่าบอทจะสแกนหน้าจอทุก 90 วินาที

## การใช้งาน

จากโฟลเดอร์โปรเจกต์ รันคำสั่ง:

```bash
python bot.py
```

หลังจากนั้นบอทจะเริ่มทำงานและคอยตรวจจับข้อความตามเงื่อนไขที่กำหนด 
กด `Ctrl + C` เพื่อหยุดการทำงาน

## วิธีการทำงาน

1. จับภาพจากพื้นที่ที่กำหนดไว้
2. แปลงภาพเป็นข้อความด้วย OCR
3. แยกข้อความเป็นบรรทัด
4. ตรวจสอบว่าบรรทัดใหม่หรือยังเคยเห็นแล้ว
5. เทียบข้อความกับ `TARGET_TEXTS`
6. ถ้าพบตรงกับคำที่กำหนด ส่งข้อความไป Discord

## ปัญหาที่พบบ่อย

### 1) OCR อ่านข้อความไม่ถูก

- ปรับ `REGION` ให้ตรงกับข้อความจริง
- เพิ่มความคมชัดของหน้าจอ
- ปรับขนาดและตำแหน่งหน้าจอให้เหมาะสม
- ใช้ font หรือธีมที่ชัดเจน

### 2) ไม่ส่งข้อความไป Discord

- ตรวจสอบว่า `DISCORD_WEBHOOK_URL` ถูกต้อง
- ตรวจสอบว่า webhook ยัง active อยู่
- ดู output จาก terminal ว่ามี error อะไรเกิดขึ้นหรือไม่

### 3) แจ้งเตือนซ้ำมากเกินไป

- ปรับ `MAX_SEEN_LINES` หรือปรับ `TARGET_TEXTS`
- ตรวจสอบว่าบอทกำลังอ่านโดเมนหรือข้อความที่ซ้ำกันมากเกินไป

## ข้อควรระวัง

- โค้ดนี้ใช้ OCR กับภาพหน้าจอแบบ real-time ดังนั้นอาจมีความผิดพลาดจากแสง สี หรือรูปแบบตัวอักษร
- ควรปรับค่าพิกัดและ keyword ให้เหมาะกับเกมหรือแชทที่กำลังใช้งานจริง
- การใช้ Discord Webhook ควรทำอย่างระมัดระวังและไม่เปิดเผย URL ในที่สาธารณะ

## หมายเหตุ

โครงการนี้ออกแบบให้ใช้สำหรับการแจ้งเตือนแบบส่วนตัวและสำหรับการทดลองใช้งานตามความเหมาะสมของผู้ใช้งาน หากต้องการปรับปรุง เช่น เพิ่มการบันทึก log, รองรับหลายช่อง Discord, หรือเชื่อมต่อกับระบบอื่น สามารถต่อยอดได้ต่อไป
