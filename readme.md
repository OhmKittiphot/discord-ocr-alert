# Discord OCR Alert

โปรเจกต์นี้เป็น Python bot ที่ใช้ OCR อ่านข้อความจากหน้าจอ แล้วแจ้งเตือนผ่าน Discord เมื่อพบคำหรือข้อความที่กำหนดไว้

> โค้ดนี้ทำงานโดยการจับภาพจากบริเวณหน้าจอที่กำหนดไว้ แล้วใช้ Tesseract OCR เพื่ออ่านข้อความก่อนตรวจจับ keyword ที่ต้องการ

## ภาพรวม

บอทนี้เหมาะสำหรับกรณีที่ต้องการตรวจจับข้อความที่ปรากฏบนหน้าจอ เช่น แชท เกม หรือหน้าต่างข้อความที่เปิดอยู่ โดยจะ:

- จับภาพจากตำแหน่งที่กำหนดบนหน้าจอ
- อ่านข้อความด้วย OCR
- ลองแยกแยะบรรทัดข้อความใหม่และข้อความที่เคยเห็นแล้ว
- ตรวจหา keyword ที่ระบุไว้
- ส่งข้อความแจ้งเตือนไปยัง Discord Webhook

## คุณสมบัติ

- ตรวจจับหน้าจอแบบกำหนดพื้นที่ (screen region)
- ใช้ Tesseract OCR อ่านข้อความจากภาพ
- คัดกรองข้อความที่ซ้ำและป้องกันการแจ้งเตือนซ้ำ
- แยกข้อความที่ตรงกับ keyword ที่กำหนด
- ส่งแจ้งเตือนไปยัง Discord ผ่าน Webhook
- ทำงานแบบวนลูปตามช่วงเวลาที่กำหนด

## โครงสร้างไฟล์

- `bot.py` - ไฟล์หลักที่มี logic ทั้งหมด
- `requirements.txt` - รายการ dependency
- `readme.md` - เอกสารคู่มือการใช้งาน

## ข้อกำหนดเบื้องต้น

ก่อนใช้งาน ต้องมีดังนี้:

- Python 3.9 หรือใหม่กว่า
- Tesseract OCR ติดตั้งบนเครื่องแล้ว
- Windows (เนื่องจากโค้ดตั้งค่า path ของ Tesseract แบบ Windows)
- Discord Webhook URL สำหรับช่องที่ต้องการรับแจ้งเตือน

## การติดตั้ง

1. เปิด terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์
2. ติดตั้ง dependency

```bash
pip install -r requirements.txt
```

## การติดตั้ง Tesseract OCR

หากยังไม่มี Tesseract ให้ติดตั้งจากลิงก์ด้านล่าง:

- https://github.com/UB-Mannheim/tesseract/wiki

หลังติดตั้งแล้ว ตรวจสอบด้วยคำสั่ง:

```bash
tesseract --version
```

หาก Tesseract ไม่อยู่ใน PATH หรือใช้เวอร์ชันที่ต่างจากค่า default ให้กำหนด path ในไฟล์ `bot.py` เช่น:

```python
pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
```

## การตั้งค่าเริ่มต้น

เปิดไฟล์ `bot.py` และแก้ค่าตรงส่วนที่อยู่ด้านบนของไฟล์:

```python
# ถ้าใช้ Windows และยังไม่ได้ตั้ง PATH ให้ tesseract ให้เปิดบรรทัดล่างแล้วใส่ path จริง
pytesseract.pytesseract.tesseract_cmd = r"C:\Program Files\Tesseract-OCR\tesseract.exe"

# พื้นที่จอที่แชท Roblox แสดงผล (ต้องวัดพิกัดจริงจากจอคุณ)
REGION = {"top": 500, "left": 20, "width": 500, "height": 200}

# คำ/วลีที่ต้องการให้จับ (พิมพ์เล็กใหญ่ไม่สำคัญ)
TARGET_TEXTS = [
    "Secret",
    "Eternal",
    "Divine",
]

# Discord Webhook URL ของคุณ
DISCORD_WEBHOOK_URL = "https://discordapp.com/api/webhooks/..."

# ความถี่ในการสแกนจอ (วินาที)
CHECK_INTERVAL = 90

# จำนวนบรรทัดล่าสุดที่จะจำไว้ (กันไม่ให้แจ้งซ้ำ)
MAX_SEEN_LINES = 300
```

### 1) ตั้งค่าพื้นที่หน้าจอ (REGION)

`REGION` คือบริเวณของหน้าจอที่ต้องการให้ bot อ่านข้อความ เช่น บริเวณแชทหรือข้อความที่ปรากฏบนเกม

ค่าที่ต้องปรับ:

- `left` : ตำแหน่งแนวนอนเริ่มต้น
- `top` : ตำแหน่งแนวตั้งเริ่มต้น
- `width` : ความกว้างของพื้นที่
- `height` : ความสูงของพื้นที่

> ควรตั้งให้ครอบคลุมเฉพาะข้อความที่ต้องการสแกนเท่านั้นเพื่อให้ OCR แม่นยำและลดการแจ้งเตือนผิดพลาด

### 2) ตั้งค่าคำที่ต้องการจับ (TARGET_TEXTS)

```python
TARGET_TEXTS = [
    "Secret",
    "Eternal",
    "Divine",
]
```

ระบบจะตรวจสอบว่าบรรทัดใดมีคำเหล่านี้หรือไม่ และถ้าพบจะส่งข้อความแจ้งเตือนทันที

### 3) ตั้งค่า Discord Webhook

```python
DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/your_webhook_url"
```

> ควรเก็บ URL นี้เป็นความลับ และอย่าเผยแพร่สู่สาธารณะ เพราะคนอื่นสามารถส่งข้อความเข้าช่องได้

### 4) ตั้งค่าความถี่และการจำบันทึก

```python
CHECK_INTERVAL = 90
MAX_SEEN_LINES = 300
```

- `CHECK_INTERVAL` คือระยะเวลาที่ bot สแกนหน้าจอหนึ่งรอบ
- `MAX_SEEN_LINES` คือจำนวนบรรทัดที่เก็บไว้เพื่อป้องกันการแจ้งเตือนซ้ำ

## การใช้งาน

รันโปรเจกต์ด้วยคำสั่ง:

```bash
python bot.py
```

จากนั้น bot จะเริ่มทำงานและตรวจจับข้อความตามเงื่อนไขที่ตั้งค่าไว้ หากต้องการหยุด ให้กด:

```bash
Ctrl + C
```

## วงจรการทำงาน

1. จับภาพจากพื้นที่หน้าจอที่กำหนด
2. อ่านภาพด้วย OCR
3. แยกข้อความเป็นบรรทัด
4. ตรวจสอบว่าบรรทัดนั้นเป็นข้อความใหม่หรือยัง
5. เทียบกับ `TARGET_TEXTS`
6. ถ้า match ให้ส่งข้อความไป Discord

## ปัญหาที่พบบ่อย

### OCR อ่านข้อความผิดหรือไม่แม่น

- ปรับค่าพิกัดใน `REGION`
- ลดพื้นที่ตรวจจับให้เล็กลงเพื่อให้ข้อความชัดขึ้น
- ปรับความคมชัดและแสงบนหน้าจอ
- ใช้ฟอนต์หรือธีมที่อ่านง่ายขึ้น

### ไม่ส่งข้อความไป Discord

- ตรวจสอบว่า `DISCORD_WEBHOOK_URL` ถูกต้อง
- ตรวจสอบว่า webhook ยัง active อยู่
- ดูข้อความ error ที่ terminal หรือ command prompt

### แจ้งเตือนซ้ำมากเกินไป

- ปรับ `MAX_SEEN_LINES`
- ปรับ `TARGET_TEXTS` ให้มีความเฉพาะเจาะจงมากขึ้น
- ตรวจสอบว่าข้อความที่ OCR อ่านออกมาซ้ำกันมากเกินจริง
